# Project Plan

Этот файл фиксирует стратегическое направление проекта, чтобы развитие сайта не превращалось в набор случайных правок.

## Текущее направление

Проект сейчас является персональным статическим сайтом Anton Dorovskikh с главной страницей, социальными ссылками и набором браузерных игр. Главная цель ближайшего этапа — сделать сайт аккуратным портфолио: понятным, быстрым, адаптивным и удобным для демонстрации опыта.

## Ближайшие улучшения

- Заполнить секции `WORK` и `CONTACT` реальным содержимым.
- Почистить `styles/main.css`: убрать дубли, исправить спорные CSS-значения, привести адаптив к понятной структуре.
- Улучшить мобильное меню: переключение через CSS-классы, закрытие после клика по пункту, доступные кнопки.
- Добавить SEO и social preview: description, Open Graph, Twitter meta, preview image.
- Оптимизировать изображения: размеры, форматы, lazy loading там, где это уместно.
- Оформить игры карточками с названием, коротким описанием и ссылкой запуска.
- Добавить базовые проверки качества: HTML/CSS validation, проверка ссылок, будущие smoke-тесты.

## Будущий путь

После стабилизации текущего статического сайта можно рассмотреть миграцию на React. Backend на Node.js и база данных должны появляться только под конкретную задачу: например, админка, динамические проекты, статистика, авторизация или хранение данных.

CI/CD переведен на первый GitLab-этап в режиме `notify-only + checks`: pipeline выполняет базовые проверки и отправляет Telegram-уведомления, но реальный deploy пока выключен. Следующий этап — добавить стабильный deploy в GitLab и расширить уведомления результатом деплоя.
